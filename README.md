# JXUFE-SE-rename-tools

班会材料一键批量重命名工具。将班会材料文件一键重命名为统一格式：`{专业班级} {班会主题} 班会材料{扩展名}`。

## 使用方法

```bash
python main.py
```

操作步骤：

1. 点击 **选择** 按钮，选中存放班会材料的文件夹。
2. 输入 **班会主题**（例如：心理健康教育）。
3. 点击 **查看预期结果**，预览重命名效果。
4. 确认无误后，点击 **批量命名** 执行。
5. 如果操作失误，点击 **撤回本次命名** 恢复。

## 配置文件

专业关键词、简称和干扰词配置在 `config.json` 中，支持用户自行编辑：

```json
{
    "abbreviations": {
        "软件工程": "软件",
        "物联网工程": "物联网",
        "物联网工程（低空应用技术）": "物联网低空",
        "软件工程（中外合作办学）": "软件中外"
    },
    "noise_words": ["软件与物联网工程学院", "软件学院", ".7z"],
    "major_words": {
        "物联网工程（低空应用技术）": ["低空应用技术", "低空应用", ...],
        "物联网工程": ["物联网工程专业", "物联网工程", ...],
        "软件工程（中外合作办学）": ["软件工程（中外合办）", ...],
        "软件工程": ["软件工程专业", "软件工程", ...]
    }
}
```

- `abbreviations`：专业简称映射，键为专业标准名称，值为输出用的简称
- `noise_words`：干扰词列表，匹配前会从文件名中移除
- `major_words`：专业关键词配置，键为专业标准名称，值为识别用的关键词列表（排在前面的优先匹配）

添加新专业：在 `major_words` 和 `abbreviations` 中各加一个键值对。

## 项目结构

```
├── main.py           # GUI 界面入口
├── core.py           # 核心重命名逻辑
├── utils.py          # 工具函数
├── config.json       # 专业关键词配置
├── resources/        # 图标资源
└── main.spec         # PyInstaller 打包配置
```

## 打包为 exe

```bash
pyinstaller main.spec
```

打包产物输出到 `dist/` 目录。

## 环境要求

- Python 3.7+
- 无外部依赖，仅使用 Python 标准库
- 仅支持 Windows
